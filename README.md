# Operating System & Shell Programming Programs (BCA Sem 5)  

This repository contains my **OS & Shell Programming programs from BCA Semester 5**, uploaded **week by week**.  
The programs cover basics of OS & Shell Programming and advanced concepts introduced in the semester.  

---

## 📂 Folder Structure  

- **Week-1/**  → To introduce OS-related basic programming by working with process IDs and CPU time concepts.
- **Week-2/**  → To understand fundamental OS performance metrics like CPU utilization and throughput.
- **Week-3/**  → To store and manipulate process-related data using arrays.
- **Week-4/**  → To represent process information using C structures.
- **Week-5/**  → To calculate waiting and turnaround times for processes and understand Gantt charts.

    

---

## ▶️ How to Run  

1. Install VirtualBox (Oracle VirtualBox).  
2. Install Ubantu and import in VirtualBox.
3. Write the program in notepad and run the program in the terminal box of VirtualBox using special commands
